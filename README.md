# mod_simplejournal

Diário de reflexão simples para Moodle.

Cada instância da atividade representa um diário/reflexão. O aluno escreve uma única entrada privada e pode atualizá-la. Professores com a capacidade `mod/simplejournal:viewall` usam um seletor de alunos para ler cada reflexão.

## Características

- Editor de texto do Moodle.
- Uma entrada por aluno e por diário.
- Entrada privada: outros alunos não veem o conteúdo.
- Sem notas e sem envio de arquivos.
- Relatório simples por aluno.
- Backup e restore com dados dos usuários.
- Privacy API.
- Compatível com Moodle 4.5 ou superior.

## Instalação

Copie a pasta `simplejournal` para `mod/simplejournal` e acesse a administração do Moodle para concluir a instalação.
